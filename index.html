Gmail setup

Automatic email requires the local server and a Gmail app password (usually requires 2-Step Verification). Don't enter your password on this page.

In PowerShell, from this project folder, run:

npm install
$env:GMAIL_ADDRESS = "you@gmail.com"
$secure = Read-Host "Gmail app password" -AsSecureString
$env:GMAIL_APP_PASSWORD = [System.Net.NetworkCredential]::new("", $secure).Password
npm start

Then open http://127.0.0.1:3000. Keep the terminal open while using the app. Use a private computer and never commit or share the app password.

Way Home is not a medical, legal, or sobriety assessment. If you've been drinking, choose a sober ride.
